# 本地測試

## 測試擴充功能
1. 終端機下進入專案目錄，執行 `npm ci` 安裝所有相依套件。
2. 執行 `npm run test:manual` 建構測試套件及啟動測試伺服器。
3. 瀏覽器進入擴充功能管理頁面，開啟「開發人員模式」載入 `dist` 資料夾以安裝之。
4. 瀏覽器進入 `http://localhost:5173/` ，即可人工測試此擴充功能。
5. 更改程式碼後，須存檔並重新執行步驟 2~3，再重新整理頁面，以測試新的程式。

## 自動化測試
1. 終端機下進入專案目錄，執行 `npm ci` 安裝所有相依套件。
2. 執行 `npm run test` 開始自動化測試，包括以下幾個：
   - **單元測試**：測試模組能否在瀏覽器環境下正常運作（透過無頭瀏覽器）。可用 `npm run test:unit` 單獨執行。
   - **端對端測試**：測試擴充套件安裝後能否正常運作（透過本地伺服器）。可用 `npm run test:e2e` 單獨執行。
3. 可用環境變數：
   - `NHITW_PORT`：指定本地測試伺服器使用的通訊埠。
   - `NHITW_BROWSER_EXE`：指定要測試的瀏覽器執行檔（限 Chromium 系）。
   - `NHITW_BROWSER_HEADED`：單元測試以有頭模式開啟瀏覽器。
   - `NHITW_BROWSER_KEEP`：端對端測試完成後保持瀏覽器及本地伺服器開啟，供使用者進行其他測試，直至使用者關閉瀏覽器。
